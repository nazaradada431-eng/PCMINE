# PCMINE

Игра про сборку майнинг-ПК: апгрейдер с колесом, майнинг-ферма, магазин деталей и тап-станция. Обычный статический сайт, сборка не нужна.

## Структура

```
index.html        страница
css/              стили (tailwind.css уже собран, style.css свои)
js/data/          каталог деталей и промокоды (только хеши)
js/core/          состояние, сохранение, звук, форматирование
js/ui/            отрисовка интерфейса и колеса
js/features/      апгрейд, перетаскивание, ферма, инвентарь, промокоды
```





## Промокоды

В `js/data/promos.js` хранятся только SHA-256 хеши кодов и описание наград. Сами коды в репозитории не лежат. Чтобы добавить код, посчитайте хеш строки `pcmine:<код в нижнем регистре>` и добавьте запись в список. Коды многоразовые.

Это защита от случайного просмотра кодов, а не от взлома: игра работает целиком в браузере, и любой желающий может изменить своё сохранение.

## Сохранение

Прогресс хранится в `localStorage` и сохраняется каждые 5 секунд, при действиях и при закрытии вкладки. За время отсутствия ферма начисляет доход, но не больше чем за 8 часов.
